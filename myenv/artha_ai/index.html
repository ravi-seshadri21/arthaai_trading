Step 2 — Authenticate Each Platform
Upstox — One-Click Login
After saving your API Key and API Secret above, click the button to complete OAuth login automatically.
Your access token will be saved — no manual copy-pasting needed.
Redirect URI to set in Upstox Developer Portal → http://127.0.0.1:8000/upstox/callback
Groww — Generate Token
After saving your API Key + Secret above, first approve the session on your phone:
Groww app → Profile → Trading APIs → Approve pending session → then click Generate Token.
Token expires daily at 6 AM IST — regenerate each morning
CoinDCX — Test Connection
CoinDCX uses HMAC authentication — no daily login needed.
Just save your API Key + Secret above and test the connection once.
Generate keys: CoinDCX app → Settings → API Management
Setup Guide

• Upstox — Save API Key + Secret → click Login with Upstox → approve login → token auto-saved ✓ · Renew daily

• Groww — Save API Key + Secret → approve in Groww app → click Generate Token → token saved ✓ · Renew daily at 6 AM

• CoinDCX — Save API Key + Secret → click Test Connection → connected ✓ · No daily renewal needed
